### Практика. Упражнение про кассовый чек

```  
Наименование товара         Кол-во         Цена            Стоимость   
  
Ноутбук                       2        45000.00 руб       90000.00 руб
Мышь                          3         1500.00 руб        4500.00 руб
......................................................................
Итого                                                     94500.00 руб
Скидка 15%                                               -14175.00 руб
Налог NV 8.0%                                             +6426.00 руб
......................................................................
Общая сумма                                               86751.00 руб
```  

Мы производим кассовый аппарат, способный выдавать чеки.
Принимает от пользователя 4 параметра для одного или нескольких товаров:
 - Название
 - Количество 
 - Цена
 - Буквенный код штата

По общей цене без налога мы можем рассчитать скидку.                          
| Сумма заказа | Ставка скидки |
| --- | --- |
| > 1000 | 3% |
| > 5000 | 5% |
| > 7000 | 7% |
| > 10000 | 10% |
| > 50000 | 15% |

По заданным 2-буквенным кодам штата мы можем рассчитать ставку налога.
| Штат | Ставка налога |
| --- | --- |
| UT | 6,85% |
| NV | 8,00% |
| TX | 6,25% |
| AL | 4,00% |
| CA | 8,25% |
   
### Тесты на кассовый чек
    
Придумать, какие нужны тесты:
  - Создаем пустой заказ. Проверяем, что сумма 0 
  - Добавляем в заказ 1 товар в кол-ве 1 шт с ценой 100. Проверяем, что сумма 100
  - Добавляем налог NV 8% к предыдущему кейсу. Проверяем, что сумма 100 - 8%
  - Добавляем в заказ 1 товар в кол-ве 3 шт с ценой 100 в штате NV. Проверяем сумму
  - Несколько товаров с суммой < 1000 в штате NV. Проверяем сумму
  - Товары с суммой > 1000. Срабатывает скидка 3%, проверяем сумму
  - То же самое для других скидок
  - Печатаем чек в один или несколько тестов
  - То же самое для других налогов (нам важно сделать работающий продукт хотя бы в одном штате)
  - ...
  
Подумать, как могут выглядеть DSL-style тесты

#### Пример без DSL

```python
order = Order()
order.add_line_item(
    "Laptop",
    2,
    Rub(45000.00),
)
order.add_line_item(
    "Mouse",
    3,
    Rub(1500.00),
)
order.set_state("NV")

receipt = order.create_receipt(ReceiptFormatter())

assert receipt == EXPECTED_RECEIPT
```

#### Пример DSL
```python
receipt = Create.receipt().with_formatter(ReceiptFormatter()).for_order(
    Create.order_line_item(2, "Laptop").with_price(Rub(45000.00)).please(),
    Create.order_line_item(3, "Mouse").with_price(Rub(1500.00)).please(),
).in_state("NV").please()

assert receipt == EXPECTED_RECEIPT
```
